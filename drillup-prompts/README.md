# DrillUp prompt library (recreated)

These 79 prompts were rewritten from scratch by watching each public example video on drillup.io (frames and voiceover). They are not the original paywalled texts, but they follow the same idea: paste one into Claude (Claude Code works best), let it build the scenes in code (Remotion / React / Three.js) and render the video.

Talking Head prompts expect you to film your own clip first; Claude adds the captions and motion design on top.
