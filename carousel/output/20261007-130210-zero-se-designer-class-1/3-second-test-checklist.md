# Zero Se Designer · Class 1 — The 3-second test

Apna design kisi ko 3 second ke liye dikhao (ya khud 3 second mein dekho). Phir pucho:

- [ ] **Kya hai?** — Offer / event / product turant samajh aaya?
- [ ] **Kiske liye hai?** — Sahi log (customer, guest, student) ko pata chala ki ye unke liye hai?
- [ ] **Ab kya karna hai?** — Date, address, phone ya next step ek jagah, saaf dikh raha hai?

Teeno ka jawab nahi mila = design fail. Fix karne ke 3 steps:

1. Message ek line mein likho.
2. Sabse important cheez sabse badi karo.
3. Har element se pucho: ye message mein help karta hai? Nahi to delete.
